# Address-Book-in-C

A simple Address Book application developed in C for storing and managing contact details efficiently through the command line.

## Features

* Add new contacts
* View all contacts
* Search contacts by name or phone number
* Edit existing contacts
* Delete contacts
* File handling for data storage
* Simple menu-driven interface

## Technologies Used

* C Programming
* Structures
* Functions
* File Handling
* Arrays and Strings

## Project Structure

```bash
AddressBook/
│── main.c
│── contact.c
│── contact.h
│── file.c
│── file.h
│── README.md
```

## How to Run

### Compile

```bash
gcc main.c contact.c file.c -o addressbook
```

### Execute

```bash
./addressbook
```

## Sample Menu

```text

5. Delete Contact
```
